# Plano de Desenvolvimento: Sistema de Apresentação OBA Online

## 🎯 Objetivo
Criar uma plataforma de apresentação visualmente impactante, profissional e alinhada com a identidade visual da Oficina Belas Artes, servindo como a vitrine estratégica do projeto "Curso Online OBA".

## 🛠️ Stack Tecnológica
- HTML5 Semântico
- Vanilla CSS (Design Premium, Animações, Responsividade)
- Javascript (Navegação, Chart.js para gráficos)

## 📌 Estrutura da Apresentação
1. **Intro (The Art of Scale):** Vídeo ou animação de fundo com a logo OBA.
2. **Visão Geral:** O propósito "A arte é para todos" de forma inspiradora.
3. **Arquitetura de Cursos:** Cards interativos mostrando os 3 Níveis (Fundamentos, Técnicas, Especializações).
4. **Modelo de Negócio:** Gráficos de pizza (Divisão de Lucros) e Barras (Prototipagem de faturamento).
5. **A Mascote Arty:** Seção dedicada ao branding e experiência do usuário.
6. **Roadmap de Lançamento:** Linha do tempo visual dos marcos (Fase 1 a 4).
7. **Conclusão:** Call to action para início imediato.

## 🎨 Identidade Visual (Estimada)
- **Cores Predominantes:** Laranja Vibrante, Preto Charcoal, Branco Papel.
- **Tipografia:** Sans-serif moderna (Inter/Outfit).
- **Estilo:** Limpo, artístico, com uso de pinceladas e texturas de papel/tela se possível.
